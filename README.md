# My Notes

A notes app built with Expo and React Native.

## Install

```bash
git clone https://github.com/T3rr8us-P4nk/mynotes.git
cd mynotes
npm install
```

## Run

```bash
npx expo start
```

## Build Android APK

```bash
npm install -g eas-cli
eas login
eas build -p android --profile preview
```
